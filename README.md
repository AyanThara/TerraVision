# TerraVision

Satellite image classification project using the EuroSAT RGB dataset.

## Structure
- `data/`: Raw and processed datasets
- `notebooks/`: Exploration and dataset inspection scripts (`inspect_dataset.py`)
- `src/`: Source code
- `models/`: Trained model checkpoints
- `results/`: Output artifacts and evaluation visualizations
- `docs/`: Documentation

## Phase 1.3: Dataset Inspection
Run the dataset inspection script:
```bash
python notebooks/inspect_dataset.py
```
